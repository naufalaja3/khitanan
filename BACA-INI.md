# 📸 Cara Menambahkan Foto

Letakkan foto anak yang dikhitan di folder ini dengan nama:

```
farrel.jpg
```

### Syarat foto:
- **Format**: JPG / JPEG / PNG (semua bisa)
- **Nama file**: `farrel.jpg` (persis, huruf kecil semua)
- **Ukuran ideal**: persegi (1:1) agar tidak terpotong aneh — misalnya 400×400 px atau 600×600 px
- **Ukuran file**: sebaiknya di bawah 500 KB agar website cepat dimuat

### Jika nama file berbeda:
Buka `index.html`, cari semua teks `img/farrel.jpg` (ada 2 tempat: cover & kartu anak),
lalu ganti dengan nama file foto kamu, contoh:

```
img/foto-anakku.jpg
```

### Struktur folder yang benar:
```
undangan-khitanan/
├── index.html
├── README.md
└── img/
    └── farrel.jpg   ← taruh di sini!
```

Setelah foto diletakkan, push ulang ke GitHub dan foto akan muncul di website. ✅
